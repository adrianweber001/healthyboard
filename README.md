# Healthyboard

https://healthyboard.netlify.app/

Healthyboard ist ein statisches CSV-Analyse-Dashboard (HTML, CSS und JavaScript). Es läuft lokal im Browser, ohne Server. Die Nieren-Beispieldaten sind erfunden und an den UCI-Chronic-Kidney-Disease-Datensatz angelehnt. Das Projekt lässt sich auf Netlify bereitstellen (`publish = "."`).

## Königsblatt

Im Ordner `koenigsblatt/` liegt ein eigenständiges Kartenspiel, das mit dem Dashboard nichts zu tun hat: Poker ohne Glück für zwei Spieler, im Browser gegen den Computer spielbar (`koenigsblatt/index.html`). Die Regeln stehen in `koenigsblatt/REGELN.md`.
